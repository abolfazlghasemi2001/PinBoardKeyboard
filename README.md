# PinBoard Keyboard

کیبورد اندرویدی (IME) برای ذخیره و درج سریع متن‌های پرکاربرد — شماره حساب، آدرس، امضای ایمیل، پاسخ‌های آماده و… .

![CI](https://github.com/abolfazlghasemi2001/PinBoardKeyboard/actions/workflows/build.yml/badge.svg)

## امکانات

**مدیریت پین‌ها**
- افزودن، ویرایش، حذف (با قابلیت **بازگردانی**) و کشیدن برای حذف
- جستجوی زنده در عنوان و متن
- دسته‌بندی کامل: ساخت، تغییر نام و حذف دسته (حذف دسته پین‌ها را پاک نمی‌کند)
- سنجاق کردن پین‌های مهم به بالای فهرست
- مرتب‌سازی: جدیدترین / پرکاربردترین / الفبایی

**کیبورد**
- درج متن با یک ضربه، مستقیماً در هر برنامه
- فیلتر دسته‌ها روی خود کیبورد و چیدمان بر اساس بیشترین استفاده
- کلیدهای واقعی: فاصله، Enter هوشمند (اجرای اکشن فیلد مثل Search/Send) و **Backspace با تکرار خودکار هنگام نگه‌داشتن**
- تعویض امن کیبورد (`ABC`) روی همهٔ نسخه‌های اندروید، با fallback به انتخابگر کیبورد
- پیش‌نمایش متن کامل با نگه‌داشتن روی پین
- چیدمان جداگانه برای حالت افقی

**کیفیت**
- معماری تمیز: `Repository` تک‌منبعِ‌حقیقت + `ViewModel` + `StateFlow`؛ تغییرات در صفحهٔ مدیریت **بی‌درنگ** روی کیبورد دیده می‌شود
- ذخیره‌سازی رمزنگاری‌شده با `EncryptedSharedPreferences` (با fallback امن) و مهاجرت خودکار از دادهٔ نسخهٔ ۱
- خروج داده از دستگاه در Auto Backup مسدود شده است
- شناسه‌های `UUID` (بدون تداخل `currentTimeMillis`)
- `RecyclerView` با `DiffUtil`، Material 3، پشتیبانی RTL و دارک‌مود، دسترس‌پذیری (contentDescription)
- بومی‌سازی فارسی و انگلیسی؛ بدون رشتهٔ hardcode
- تست‌های واحد JVM برای منطق فیلتر/مرتب‌سازی + CI شامل `test`، `lint` و ساخت APK

## معماری

```
data/   PinItem, PinCategory      مدل‌های داده (UUID)
        PinQuery, PinSort         منطق خالص فیلتر و مرتب‌سازی (تست‌پذیر)
        PinStore                  لایهٔ ذخیره‌سازی رمزنگاری‌شده + مهاجرت v1→v2
        PinRepository             تک‌منبعِ‌حقیقت درون‌پردازه‌ای با StateFlow
ui/     MainActivity, MainViewModel, PinListAdapter
ime/    PinBoardIME, KeyRepeat    سرویس کیبورد و کلید تکرارشونده
```

## ساخت

```bash
./gradlew assembleDebug      # ساخت APK دیباگ
./gradlew testDebugUnitTest  # اجرای تست‌ها
./gradlew lintDebug          # بررسی lint
```

نیازمندی‌ها: JDK 17، Android SDK 35 (AGP 8.7.3 / Gradle 8.9 / Kotlin 2.0.21)، `minSdk 23`.

## فعال‌سازی کیبورد

۱. اپ را باز کنید و چند پین بسازید.
۲. از منوی اپ یا دکمهٔ «فعال‌سازی کیبورد در تنظیمات»: Settings → System → Languages & input → On-screen keyboard → **کیبورد پین‌بورد** را روشن کنید.
۳. در هر فیلد متنی، از انتخابگر کیبورد، پین‌بورد را انتخاب کنید.

## نکته

پین‌بورد یک کیبورد «درج سریع متن» است، نه کیبورد حروف. برای تایپ معمولی کلید `ABC` شما را به کیبورد بعدی سیستم می‌برد.

## حریم خصوصی

تمام داده‌ها فقط روی دستگاه و به‌صورت رمزنگاری‌شده ذخیره می‌شوند؛ اپ هیچ مجوز شبکه‌ای ندارد و هیچ داده‌ای ارسال نمی‌کند.
