# PinBoard Keyboard

کیبورد اندرویدی برای ذخیره و درج سریع متن‌های پرکاربرد.

## امکانات
- ذخیره متن‌های پرکاربرد
- عنوان‌گذاری
- دسته‌بندی
- فیلتر بر اساس دسته
- ویرایش
- حذف با نگه‌داشتن روی پین
- درج مستقیم متن در برنامه‌های دیگر
- باز کردن مدیریت پین‌ها از داخل کیبورد
- رابط فارسی و RTL
- ذخیره محلی با SharedPreferences و Gson

## ساخت
پروژه را در Android Studio باز کنید و Gradle Sync را انجام دهید.

## فعال‌سازی کیبورد
بعد از نصب:
Settings → System → Keyboard / Languages & input → On-screen keyboard → PinBoard Keyboard

سپس در هر فیلد متنی، کیبورد PinBoard را انتخاب کنید.

## نکته
این نسخه «صفحه پین» را به عنوان یک IME ارائه می‌کند و برای تایپ حروف، دکمه ABC شما را به کیبورد بعدی سیستم منتقل می‌کند.
